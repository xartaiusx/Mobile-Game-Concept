# Enemy Art

Reserved for project-authored enemy visuals. The current humanoid wrapper is [`BasicEnemyVisual.prefab`](../Prefabs/BasicEnemyVisual.prefab), using a selected model from [third-party assets](../../ThirdParty/README.md).

Attach visuals beneath the gameplay prefab's `VisualRoot`. Keep health, combat, and collision behavior on the gameplay root. See the [development guide](../../../DEVELOPMENT.md).
